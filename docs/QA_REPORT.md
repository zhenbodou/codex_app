# 本次修复与验证记录

日期：2026-10-23

## 修复内容

- 登录页默认使用独立浅色主题，避免继承工作区深色设置。增加深色切换、明确的字段标签、密码可见切换和输入校验。
- 登录页不依赖从透明状态恢复的入场动画；主按钮在未填写时仍保持清楚可读。
- 限制重复认证提交；登出即时清理本地状态，旧认证/聊天请求不能覆盖新的登录状态。
- 会话的消息、生成状态和草稿分别保存。后台会话完成不会清空前台会话的生成状态。
- 创建会话期间切换项目，不会把刚创建的会话强行切回前台；加载历史期间不发送新任务。
- 增加桌面快捷键、菜单方向键/数字选择、快捷键帮助、弹窗焦点限制与关闭后的焦点恢复。
- 菜单中的 Esc 只关闭菜单，不冒泡触发停止生成。详情栏在窄窗口中与聊天区并排，输入工具栏换行。
- 消息历史加载失败时显示错误和重试入口。
